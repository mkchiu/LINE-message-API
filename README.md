# LINE-message-API

# LINE 群組定時自動訊息通知設定指南：
1. 前往 LINE Developer Console，建立一個 Provider，並記下你設定的 Provider 名稱：
   https://developers.line.biz/zh-hant/services/messaging-api/
2. 選擇"Create a Messaging API channel"，點擊"Create a LINE Official Account"，經過以下3個步驟：<br/>
   【登錄公司／店鋪資訊】填寫帳號資訊：帳號名稱、電子郵件帳號、公司所在國家或地區、業種，點擊下方"確定"<br/>
   【確認輸入內容】點擊"完成"<br/>
   【申請完成】<br/>
3. 申請完成後出現"您的LINE官方帳號已建立完成"頁面
4. 記住"帳號資訊"的基本ID: @999xxxx(舉例) 
5. 點擊"稍後進行認證(前往管理畫面)"
6. 同意我們使用您的資訊，點選"同意"
7. LINE官方帳號使用條款更新啟事，點選"了解並繼續使用"
8. 頁面會自動轉到 LINE Official Account Manager<br/>
   (8.1) 若尚未擁有帳號，登入 LINE 官方帳號管理後台，可免費註冊一個：https://tw.linebiz.com/login/ )<br/>
   (8.2) 成功登入後，建立新的 LINE 官方帳號。請注意：帳號名稱在修改後的 7 天內無法再次變更。<br/>
   (8.3) 建立LINE官方帳號：此名稱將顯示於LINE的好友名單及聊天畫面中，填寫基本訊息(EMAIL等)。<br/>
   (8.4) 上述基本訊息填寫完之後會出現 "您的LINE官方帳號已建立完成"，暫不選擇"申請認證帳號"，直接選擇"稍後進行認證(前往管理畫面)"，記憶住"帳號資訊"的基本ID: @999xxxx(舉例) 。<br/>
   (8.5) 依序點選"同意"、"了解並繼續使用"、"下一步"，點選"下一步"之後，直接點選"前往主頁"(暫不點選"增加好友人數")。<br/>
9. 彈窗：開始經營帳號前(1/2)，點擊右上角的 "X"
10. 點擊該頁面右上角"設定"，點擊之後：<br/>
    (10.1) 點擊左側選單的 設定 > 帳號設定 > 功能設定 > "接受邀請加入群組或多人聊天" (點擊變更)。<br/>
    (10.2) 點擊左側選單的 設定 > 回應設定 > 回應功能 > "加入好友的歡迎訊息" (取消選取)。<br/>
    (10.3) 點擊左側選單的 設定 > 回應設定 > 回應功能 > "自動回應訊息" (取消選取)。<br/>
    (10.4) 點擊左側選單的 設定 > 回應設定 > 回應功能 > Webhook > (下方綠色小字)"開啟Messaging API的設定畫面" (點擊綠色小字後跳頁)。<br/>
11. LINE Official Account Manager - Messaging API：<br/>
    (11.1) 點選"啟用Messaging API"<br/>
    (11.2) __選擇服務提供者：選擇上述 1 在 LINE Developer Console 所建立的 Provider 名稱，點選同意__  __(重要)__ <br/>
    (11.3) 暫不填寫 "隱私權政策"、"服務條款" (選填，可以不填寫)，直接點選確定<br/>
    (11.4) 最終會出現 [啟用Messaging API] ，直接點選確定<br/>
- - -
12. 登入 Google 雲端硬碟的 JavaScript Apps Script 平台 (Google Apps Script)
    https://script.google.com/home?hl=zh-tw
13. 成功登入後，點擊左上角" + 新專案"
14. 先將"程式嗎.gs"檔案的右側 Code Window 中的默認程式碼： function myFunction() {} 刪除
15. 再將 GitHub Code (例如：punch out) 複製黏貼到"程式嗎.gs"檔案的右側 Code Window
16. 點擊「儲存」-「將專案儲存至雲端硬碟」，將目前的 Google Apps Script 專案儲存至雲端硬碟
17. 點擊「執行」，系統會跳出提示：「需要授權」
18. 授權操作流程，依序點選以下步驟完成授權：<br/>
    ˙ 點擊「審查授權」<br/>
    ˙ 選擇你要使用的 Google 帳號<br/>
    ˙ 出現紅色警告三角圖示與訊息：「這個應用程式未經 Google 驗證」<br/>
    ˙ 點擊警告下方左側的「進階」<br/>
    ˙ 再點選「前往『未命名的專案』（不安全）」<br/>
    ˙ 在出現的授權頁面中，勾選所有要求的存取權限（或選擇「全選」）<br/>
    ˙ 點擊「繼續」，彈窗消失 <br/>
    ˙ 授權流程完成後，會自動返回 App Script 編輯頁面 <br/>
19. 此時下方的「執行紀錄」會出現錯誤訊息，錯誤訊息：doPost @ 程式碼.gs:6 ，不理會，先進行下方步驟
20. 點擊左側選單的"專案設定"，在"一般設定"的時區選擇"台北標準時間-台北(GMT+08:00)"
21. 點擊左側選單的"編輯器"
22. 在 Google Apps Script 中修改剛剛複製的 GitHub Code 中的：<br/>
    (22.1) 取得 LINE 的 Channel access token：<br/>
         (22.1.1) 登入 https://developers.line.biz/console/ ，依序操作：<br/>
         (22.1.2) 進入你在第 1 步中所建立的 Line Developers Provider<br/>
         (22.1.3) 選擇 Messaging API 頁籤<br/>
         (22.1.4) 找到 Channel access token 區塊，點擊"Issue"<br/>
         (22.1.5) 複製所產生的 access token<br/>
    (22.2) 將 Channel access token 指定到變數中<br/>
         (22.2.1) 找到程式中的 line_token (第3行) 與 token(第35行)：<br/>
         (22.2.2) 將剛剛複製的 Channel access token 貼上，作為這兩個變數的值  <br/>
    (22.3) 第 36 行的 userId 目前先保留原樣，不做更動 <br/>
    (22.4) 根據需求調整其他內容：例如可以修改： 訊息(message)、時間 (days[]、atHour()、nearMinute()) <br/>
23. 點擊右上角的 「部署」 > 選擇 「新增部署作業」 > 在左上角的 「選取類型」 中，點擊並啟用部署類型，選擇 「網頁應用程式」
24. 右側將出現相關設定欄位，請依下列方式填寫：<br/>
    ˙ 說明: 可不理會或任意輸入<br/>
    ˙ 網頁應用程式執行身分: 選擇「我」(默認選項)<br/>
    ˙ 誰可以存取: 選取「所有人」<br/>
    ˙ 接著點選 「部署」 按鈕<br/>
25. 部署完成後，複製「網頁應用程式」的網址，然後點擊 「完成」<br/>
- - -
26. 登入LINE官方管理頁面： https://manager.line.biz/ ，點選進入第 8 步所建立的帳號
27. 在帳號頁面右上角點擊 「設定」，然後在左側選單依序點選 設定 > Messaging API
28. 將第 25 步驟中複製的「網頁應用程式」網址貼入 Webhook 網址 欄位，完成後點擊 「儲存」
29. 接著再次點擊右上角的 「設定」，於左側選單中點選 設定 > 回應設定，找到 回應功能 > Webhook，並將其切換為 啟用
- - -
30. 開啟 LINE，點選「好友」，搜尋上方步驟 (8.4) 中的「帳號資訊」所提供的基本 ID，並加入好友
31. 進入指定的 LINE 群組，邀請該 ID 加入群組。若該帳號加入後自動退出，請依照步驟 (10.1) 進行相關設定調整。
32. 在群組中輸入關鍵字 id（英文小寫），此時該官方帳號會自動回覆該群組的 GROUP ID，請將此 ID 複製下來
33. 將複製的 GROUP ID，貼上至第 (22.3) 步驟中程式碼第 36 行的 userId 欄位作為其值，完成後儲存
